Lab Characteristics

  • Public endpoints for all resources
  • Shared key / API key authentication
  • No network isolation (no VNet)
  • Admin accounts enabled where available
  • Purge protection disabled for easy cleanup
  • Optimized for speed of setup and experimentation

Production Characteristics

  • Private endpoints on every resource
  • Managed identity for all authentication
  • Full VNet integration with firewall
  • Admin accounts disabled, RBAC enforced
  • Purge protection ON, soft delete enabled
  • Optimized for security, compliance, and auditability
