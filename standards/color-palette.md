## Color Usage Guidelines

### Ratio Rules
- **Primary** (60-70%): Main wall surfaces
- **Secondary** (15-20%): Accent bands, trim, window surrounds
- **Trim** (5-10%): Window frames, cornices, structural edges
- **Accent** (2-5%): Door color, signage, small decorative elements

### Best Practices
1. Limit total colors to 5-7 per building (primary, secondary, trim, accent, window glass, roof)
2. Use consistent colors per structural element (all window frames same color)
3. Accent bands between floors provide visual separation — use secondary or trim color
4. Roof and sidewalk colors can be neutral (grays) regardless of facade palette
5. Trans Clear (47) for ALL standard windows unless specifically going for stained glass

### Medium Nougat Note
LDraw color code 150 (Medium Nougat) is the official code, but some stud.io versions may not render it correctly. Color 28 (Dark Tan) is the safest visual approximation. In generation scripts, the color is assigned to a variable (e.g., `$MN = 28`) so it can be easily swapped.
