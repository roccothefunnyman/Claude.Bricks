# Azure Architecture Icons Reference (V23 - November 2025)

This document provides a complete reference of all 705 SVG icons from Microsoft's official Azure architecture icon set. Icons are organized by category, with filenames and human-readable service names for quick lookup.

## How to Use

- Icons are located in category subfolders under `azure-icons/`.
- Each icon follows the filename format: `NNNNN-icon-service-Service-Name.svg`, where `NNNNN` is a numeric identifier.
- The service name can be derived by taking the portion after `icon-service-`, then replacing hyphens with spaces. For example, `00028-icon-service-Batch-AI.svg` becomes **Batch AI**.
- To reference an icon in documentation or diagrams, use the relative path: `azure-icons/<category>/<filename>`.
