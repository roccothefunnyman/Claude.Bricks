Scenario 4: RAG Spec Generator

Retrieval-Augmented Generation for LEGO building specifications using Azure OpenAI and AI Search

GPT-4o • Azure AI Search • AI Foundry • Prompt Versioning • AI Evaluation

Overview

This walkthrough takes you through every step of executing Scenario 4, from configuring Azure OpenAI and AI Search to generating structured LEGO building specifications via a RAG pipeline, with evaluation, prompt experimentation, and production monitoring.

Scenario 4 is a GenAI pipeline that generates structured LEGO building specifications from natural language descriptions. It uses Azure OpenAI (GPT-4o) with Retrieval-Augmented Generation (RAG) to ground outputs in architectural reference materials stored in Azure AI Search. The system is deployed via AI Foundry and includes prompt versioning, evaluation, fine-tuning, and monitoring capabilities.

Step 3: Upload Training Data (Optional)

3

Upload Training Data for Fine-Tuning

Upload JSONL to Azure OpenAI for optional model fine-tuning

This step is optional. If you want to fine-tune GPT-4o on your building spec examples, upload the JSONL file to Azure OpenAI. The script returns a file ID that can be used to create a fine-tuning job.

Terminal
python upload_training_data.py \ --file data/scenario4/training_data.jsonl # Output: # Uploaded file: file-abc123def456 # Use this file ID to create a fine-tuning job
Fine-tuning is optional
The RAG pipeline works well with the base GPT-4o model and a well-crafted system prompt. Fine-tuning improves output consistency but requires at least 10 training examples and incurs additional Azure OpenAI costs.

Troubleshooting

ProblemCauseFix
Azure OpenAI 429 rate limit error TPM quota exceeded Reduce concurrent requests, increase TPM quota in Azure portal, or add retry logic with exponential backoff
AI Search index returns no results Index is empty or not created Run python index_documents.py (Step 4)
Groundedness score consistently low Poor retrieval quality or insufficient context Increase top_k, adjust chunk size, or verify index contains relevant documents
Invalid JSON in spec output System prompt not enforcing JSON format Check system prompt version in prompts/system/. Update to latest version with strict JSON instructions.
Foundry project not found Project not created or wrong credentials Run python foundry/create_project.py (Step 5a)
AuthenticationError on OpenAI calls DefaultAzureCredential not picking up identity Run az login again. Verify your identity has Cognitive Services OpenAI User role on the OpenAI resource.
Embedding dimension mismatch Index created with different embedding model Delete and recreate the index with index_documents.py. Ensure text-embedding-3-small (1536 dims) is used consistently.
